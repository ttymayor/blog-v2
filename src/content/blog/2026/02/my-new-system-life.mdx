## 前言

我的文書筆電：Acer Swift 3 (SF314-511) 有著很獨特的內顯「Iris Xe Graphics」，陪我度過了整個高中生涯（陪我度過那些沒日沒夜的特戰英豪 🤭）。總之這台文書機已經 5 歲了，隨著 Windows 11 更新，以及綁架式軟體的吹殘下，實在受不了連開個 Zed 開發都在卡頓的情況。同時我目前的主力主機不確定因為是安裝了什麼環境導致某日當機後就持續近不去系統（只能透過安全模式進入），於是對於 Windows 心生怨念而冒出了一個想法：我要裝 Linux。

## 上手過程

對於我來說，只要是有關系統類的東西，我一概不解，因此也怕玩壞我的磁碟（？）但第一個裝置被我下手的對象不是主機，是我的筆電，因為我真怕玩壞主機。但也不知道哪根筋不對，不選擇裝簡單易上手的 Ubuntu，而是幾乎都是用指令來打造的 Arch Linux。不過！我慫。偷吃步用官方的 `archinstall` 用直白的方式安裝。過程幾本上照著網路上的文章走即可我是看 [archinstall script使用教學，KDE Plasma桌面 ＋ 中文化，讓Arch Linux安裝更簡單](https://ivonblog.com/posts/archinstall-script/) 這篇文（但他站廣告有點多，甚至看起來是詐騙），總之其實都沒有什麼大礙。其實如果用指令裝的話，應該也差不多就是一個一個裝，一個一個配置。`archinstall` 真的很方便呢。不過後續的注音輸入法還是要另外裝但我覺得如果都對系統有興趣了，應該對於指令也不害怕陌生。

用了半天後，我上手還算快吧。主要是我一直很想要跟 macOS 一樣有頂部狀態列的系統樣式，比起 Windows 乾淨非常多。而我用的環境是 KDE Plasma 所以也很輕鬆的做到頂部狀態列這件事。啊...怎麼說...Linux 實在太香了，幾乎不吃資源的系統對於系統體驗跟開發的流暢感真的不是 Windows 能比的，同時，裝套件、環境、應用，也不像 Windows 一樣厚工（kāu-kang）。於是我也越來越像 Geek 那樣，持續深愛著資訊領域。

## 終端

玩 Linux 不就是要玩指令、玩終端機嗎？美化它們的過程也都真的一樣迷人。目前可能習慣的配置是 `fish shell`, `Ghostty`, `Starship`。第一個用於自動補全和優化指令提示、第二個用於終端機的美化實用性（包括切割區塊、調整區塊大小和終端主題色等等自訂）、第三個用於美化 shell。然後覺得玩 Linux 就該炫泡，所以就找了幾個指令裝逼 `tty-clock`, `fastfetch`, `cmatrix` 大概就會變成國外 TY Linux 類的影片封面。

不過個人覺得前兩個還是可能用的到啦（可能）

```bash
tty-clock -c -s -C 2
```

這個用 Ghostty 的 Splits 分屏其實也蠻有用的告訴自己時間緊迫放個時鐘這樣。

我的 Ghostty 分屏快捷鍵：

- `ctrl`+`shift`+`O` 向右分屏
- `ctrl`+`shift`+`E` 向下分屏
- `super`+`ctrl`+`shift`+`方向鍵` 控制分屏大小

用了一下後就習慣了。

## 總結

Linux 配合開發者，真的很快很流暢。裝了一遍之後就會有第二遍，現在變成主力筆電了，而且也比 Windows 亂吃效能省電很多，都以為我自己買了新機。

總之，

Welcome to Arch Linux
